# Local SEO report and next actions

Read [WORKFLOW.md](../vibelocal/references/WORKFLOW.md) and [METRICS.md](../vibelocal/references/METRICS.md). Reuse collected/imported snapshots and the current owner context. Do not start fresh paid collection merely to fill a report. For unfamiliar imports, use `import` to bound and label raw JSON arrays; ask for total coverage only if needed and unknown.

Use `report --snapshot ...` for one or more supported snapshots to create a self-contained HTML report with escaped data, no remote assets and no tracking. Review its source badges, coverage counts, timestamps and collection warnings. Fixtures remain clearly fictional; imports remain unverified imports. The report's point cards summarize a grid without pretending to be a geographic map. Open the actual output when the host supports file preview.

Add a companion owner summary in Markdown: confirmed branch and period, decision-ready findings, what is unknown, and up to five actions. Each action needs priority reason, source/date, concrete deliverable, owner, approval needed and verification date. Distinguish factual corrections from proposed content experiments. Generic advice without evidence is a recommendation, not an observed defect.

For trends, use `compare` only with complete, equivalent Maps snapshots. Label newly found/no longer found separately from numeric movement. Show metric denominators, requested versus observed coverage and sample limits. Missing or failed data remains unknown. Public rank/profile data does not establish calls, bookings, revenue or private account performance.

When owner-provided GBP/Search Console/conversion exports exist, add their actual definitions, periods and source. Avoid mixing platform metrics or attributing a change to one edit without supporting evidence. Give a concise interpretation plus one next decision, rather than a fabricated ROI claim.

Review names, hidden addresses, reviewer text and customer information before sharing. The helper removes reviewer identity fields but cannot guarantee that free text contains no personal information. Deliver real artifact paths and the current evidence state. Sending the report, publishing changes or activating repeat collection requires separate approved scope.
